# Scene style explorations v2

Ova serija mijenja cijeli dizajnerski jezik, proporcije likova, siluete, način sjenčanja i ponegdje kompoziciju. Nije riječ samo o istoj slici izvedenoj drugom slikarskom tehnikom.

1. `01_chunky_web_cartoon.png` — grubi, prenaglašeni web-game crtić
   - `01_chunky_web_cartoon_nerd_expression_v2.png` — odabrana varijanta sa smješnijim, koncentriranim izrazom štrebera
   - `01_chunky_web_cartoon_nerd_expression_v3.png` — izraženija varijanta u kojoj štreber grize vidljivi vrh jezika i blago se smješka
2. `02_minimal_mascot.png` — vrlo jednostavne maskote i simbolički oblici
3. `03_gritty_pulp_comic.png` — taman, uglat pulp-strip
4. `04_tv_web_cartoon.png` — jednostavan zapadni TV/web crtić
5. `05_midcentury_geometric.png` — geometrijska animacija iz sredine 20. stoljeća
6. `06_european_slapstick_comic.png` — europski slapstick-strip i snažne karikature
7. `07_rubber_hose_cartoon.png` — crno-bijeli rubber-hose kino-crtić
8. `08_cut_paper_collage.png` — poderani papir, karton i fizički kolaž
9. `09_four_color_linocut.png` — grubi četverobojni linorez
10. `10_wooden_boardgame_diorama.png` — drvena stolna igra i fizička diorama
11. `11_surf_punk_screenprint.png` — fluorescentni surf-punk sitotisak
