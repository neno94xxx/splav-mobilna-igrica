# Varijante stila pozadine

Sve slike zadržavaju istu osnovnu scenu kako bi se lakše usporedio samo vizualni stil.

1. `01_flat_graphic.png` — čista, ravna grafička ilustracija
2. `02_watercolor_ink.png` — tradicionalni akvarel i tinta
3. `03_retro_comic.png` — retro europski pustolovni strip
4. `04_low_poly_3d.png` — low-poly 3D diorama
5. `05_pixel_art.png` — detaljni 32-bitni pixel-art
6. `06_clay_stop_motion.png` — glina i ručno izrađena stop-motion maketa

Folder sadrži `.gdignore`, pa Godot ove koncepte neće uvoziti u projekt niti ih uključivati u APK.
